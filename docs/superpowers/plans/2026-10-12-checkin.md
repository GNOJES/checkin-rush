# 체크인까지 5분 Implementation Plan

Goal: 사용자 명세에 따른 로컬 싱글플레이 게임 완성과 검증.
Architecture: 시나리오 상수 + 순수 reducer + React 앱 화면. Date.now 경과 시간으로 마감 판정; 모든 게임 액션에 현재 시각 및 세션 ID 적용.
Tech Stack: React, TypeScript, Vite, Vitest, Playwright.
Spec: ../specs/request.txt

## Constraints

고정 시나리오, 한국어, 300초, 외부 서비스 및 공개 배포 없음. 게임 종료 후 불변, 중복 비용 금지. 실제 시간대와 무관한 가상 공항 시간.

## Review focus

- 백그라운드/마감 직전 클릭 → 액션 처리에도 마감 판정.
- 재시작 후 과거 메시지 콜백 → 세션 ID로 무시 및 effect 정리.
- 모바일 320px 및 긴 콘텐츠 → 세로 스크롤/문서 확대.
- 앱 이동 → 입력 및 화면 유지.
- 반복 힌트/비용 클릭 → 고유 단계/청구 한 번.
