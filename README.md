# 체크인까지 5분

가상 이메일·메신저·항공사 앱을 오가며 예약을 복구하고 탑승권을 발급하는 한국어 모바일 웹 퍼즐 게임입니다. 프로젝트명은 `five-minutes-to-checkin`입니다.

## 실행

Node.js 22.12 이상(개발 환경: Node 26), npm이 필요합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다(기본 `http://127.0.0.1:5173`). 설치 이후 기본 플레이에 외부 이미지·폰트·음원·서버가 필요하지 않습니다. 새로고침하면 게임이 초기화됩니다.

```sh
npm run build       # TypeScript 검사 및 dist 정적 빌드
npm run preview     # 빌드한 게임 로컬 확인
npm test            # Vitest 상태 전이 테스트
npm run test:e2e    # Playwright 실제 브라우저 플레이
```

브라우저 테스트는 설치된 Google Chrome을 사용합니다. Chrome이 없으면 `npx playwright install chromium`으로 브라우저를 설치하고 `PLAYWRIGHT_CHANNEL=chromium npm run test:e2e`로 실행할 수 있습니다. 테스트 중 로컬 서버 실행과 브라우저 프로세스 권한이 필요할 수 있습니다.

## 구현한 기능

- 이메일 목록·검색·상세·예약 상세 펼치기, 최신 탑승구 변경 메일
- 민지와의 선택형 대화, 입력 중 표시, 확대 가능한 HTML/SVG 가상 여행 서류
- 항공사 예약 조회·예약 정보·무료/유료 이름 정정·시간대·탑승구·탑승권·고객센터
- 실제 경과 시간 기반 300초 제한시간 모드와 무제한 연습 모드
- 퍼즐별 3단계 힌트와 재열람, 힌트·오답·비용 기록
- 두 가지 선택 비용 서비스, 중복 청구 방지와 무료 성공 경로
- 성공·시간 초과 엔딩, 재시작, 결과 요약 복사 및 복사 거절 시 텍스트 대안
- 앱 이동 시 입력과 진행 유지, 새 메일/답장 알림과 배지
- Web Audio로 생성한 효과음, 음소거·동작 줄이기, 시스템 동작 줄이기 설정 반영
- 모바일 세로 화면과 PC 가상 폰, 스크롤·키보드 포커스·문서 확대

## 구조

- `src/scenario.ts`: 고정 시나리오, 메일, 대화, 힌트
- `src/game.ts`: 순수 reducer, 정규화, 비용/종료/세션 규칙, 가상 시각
- `src/App.tsx`: 가상 폰, 세션 타이머·답장 예약, 홈·힌트·설정·결과
- `src/Mail.tsx`, `src/Chat.tsx`, `src/Airline.tsx`: 앱별 화면
- `src/shared.tsx`: 가상 서류·탑승권·공통 화면 요소
- `src/sound.ts`, `src/styles.css`: 효과음과 반응형 스타일
- `src/game.test.ts`, `tests/game.spec.ts`: 상태 및 브라우저 테스트

액션 처리 시에도 마감 시각을 검사하므로 지연된 타이머 콜백으로 성공 판정이 뒤집히지 않습니다. 종료 후 게임 액션을 무시하며, 재시작 시 예약 콜백을 정리하고 세션 ID로 과거 이벤트를 거부합니다. 실제 오늘 날짜·기기 시간대에 따라 정답은 변하지 않습니다.

## 검증

- Vitest 9개: 무료/유료 성공, 정답 정규화, 오답 재시도, 중복 청구, 마감 순간 결과 잠금, 연습 모드, 힌트 중복 집계, 재시작/과거 이벤트 차단, 미완료 발급 거부
- Playwright 10개: 무료 성공/재시작, 가상 시계 시간 초과와 무제한 연습, 단서/입력 유지/유료 성공, 320px 힌트/스크롤, 광고와 읽지 않은 단서 배지, 모달 키보드 포커스, 앱 전환 중 답장/재시작 취소, 힌트 12단계/320px 성공, 복사/복사 거절 대안, PC·모바일/검색/설정
- `artifacts/`에 홈·메일·항공사·문서·성공·실패 및 PC/모바일 오프닝 캡처 저장
- `docs/verification.md`에 최종 검증 결과 기록

## 범위와 제한

고정된 단일 시나리오이며, 게임 상태는 메모리에만 저장됩니다. 로그인·실제 결제·SMS·API·LLM·서버·멀티플레이·랭킹·공개 배포는 없습니다. 바코드와 여행 서류는 게임용 장식입니다. Chrome의 PC/모바일 뷰포트로 검증했으며 실제 iOS/Android 기기 및 Safari에서의 검증은 수행하지 않았습니다. 효과음은 브라우저의 오디오 정책을 따릅니다.
